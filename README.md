# NovaShop E-Commerce Website

A responsive front-end e-commerce demo made with HTML, CSS and JavaScript.

## Features
- Responsive modern design
- Product cards
- Search
- Category filtering
- Price/rating sorting
- Shopping cart drawer
- Quantity controls
- Remove items
- Persistent cart using localStorage
- Coupon code: WELCOME15
- Demo checkout modal

## Run the site
1. Extract the ZIP file.
2. Open `index.html` in your browser.

No installation is required.

## Files
- `index.html` — page structure
- `style.css` — design and responsive layout
- `script.js` — products, filters, cart and checkout logic

## Note
This is a front-end demo. Real login, payment processing, database storage, inventory management, and admin features require a backend/server.
